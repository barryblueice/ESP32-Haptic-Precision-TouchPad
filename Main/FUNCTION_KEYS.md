# 单点扩展功能键（2026-09-16）

按配置器 `docs/hid-protocol.md` 的动作表实现 13～47 共 35 个功能：
静音、播放/暂停、上一曲、下一曲、停止播放，Esc、Enter、Tab、空格、
Backspace、Delete、Insert、Home、End、Page Up/Down、Print Screen、F1～F12，
以及固定左 Ctrl 的复制、粘贴、剪切、撤销、重做、全选。

## 配置与兼容

- 当前固件继续使用配置 v3、52 字节负载，握手能力从 `0x7ff` 扩展为 `0xfff`。
  新能力 `0x800` 依赖单点能力 `0x100`；缺失时拒绝新增动作，禁用的点也校验。
- 四点分别接受 0～47，48～255 拒绝。边缘动作仍为 0～6。
- v3 的每点四字节布局、无线阈值、原有默认值均保留。
- NVS 保存和恢复保留动作编号。旧 v2 存储记录仍按五字节记录迁移：
  0～12 兼容旧反转位；13～47 的旧反转位必须为零。USB 写入仍仅接受握手声明的 v3 布局。

## 输出与持续动作

复用现有独立 Consumer Control（Report ID 7）和键盘（Report ID 8）集合，
既有描述符范围覆盖所有新增 Usage，无需改动触摸板集合。
组合键在同一报告中按下左 Ctrl 与字母，之后发送全零释放报告。
辅助队列串行发送，前一个动作及其释放完成后才发送下一个动作。

新增动作关闭持续时每次接触触发一次；开启时沿用现有 600 ms 初始延迟和
200 ms 重复间隔，每轮独立按下、释放。输出忙时跳过新的重复，不积压重复。
新增键不会因为旧移动事件的 100 ms 超时而被丢弃；取消、链路恢复和断开仍清理状态。
抬手或转入边缘解析后停止重复并完成释放。0～12 的既有行为保留，
其中原有亮度、音量和方向键的持续动作仍采用保持按下。

内部辅助动作 1～6 保留原有方向操作含义，7～12 保留，13～47 对应新增配置编号。
2.4G 传输沿用原有报文布局；接收器复用 `Main/main/SYS` 的解码及输出代码，
需要同时更新接收器固件。旧接收器会拒绝新增动作。

## 验证

功能键原有验证包含核心及配置 33、接收器 39、无线设置同步 6 项主机测试。
蓝牙现仅提供鼠标 HID，不提供这些扩展功能键；BLE 测试已改为鼠标发送与恢复测试。
新增测试遍历全部 35 个动作，覆盖四点存储恢复、v2 迁移、越界和能力拒绝、
HID Usage/修饰键、重复、释放重试、拥塞、快速抬手、点击转边缘、断开清理及无线传输。
主固件与 2.4G 接收器的功能键构建验证记录保留；蓝牙鼠标变体的构建和验收
参见 [RSTP_V2.md](RSTP_V2.md#verification)。固件路径：

- 主固件：`build/ESP32_HAPTIC_PRECISION_TOUCHPAD.bin`
- BLE 模拟鼠标：`build/validation/ble-simulated-mouse/firmware.bin`
- BLE 原生鼠标：`build/validation/ble-native-mouse/firmware.bin`
- 接收器：`../2.4G/build/ESP32-Haptic-2.4G-Receiver.bin`

这些是生产 C 代码与模拟 RTOS/NVS/传输边界的测试；未刷写设备。
实际主机按键效果、真实断电保存、USB／2.4G 下的功能键释放及重复仍需硬件验收。
