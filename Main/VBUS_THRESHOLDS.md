# VBUS 按压阈值配置（正常固件）

## 行为

| GPIO9 / VBUS_DET | 使用的字段 | 默认轻／中／重 | 允许范围 |
|---|---|---|---|
| 高 | 原有 light / medium / strong | 80 / 100 / 130；已有值保留 | 1 ≤ 轻 ≤ 中 ≤ 重 ≤ 255 |
| 低 | wirelessLight / wirelessMedium / wirelessStrong | **20 / 35 / 70** | 1 ≤ 轻 ≤ 中 ≤ 重 ≤ 100 |

按压阈值使用原始压力数值单位。100 直接参与比较，**不映射为 255**，也不缩放触摸帧中的压力。
Windows 的按压档位 1～3 选择当前组的轻／中／重，触觉强度 0～100 仍是独立设置。

选择条件是触摸板自身的 VBUS_DET，与 USB、BLE、2.4G 模式无关。例如保持 2.4G 模式但插入触摸板 USB 供电后，使用高电平组。接收器插入电脑不等于触摸板 VBUS 为高。

启动读取电平；输入任务每隔至少 10 ms 采样，连续稳定 30 ms 后确认变化。在空闲时也通过带超时的任务等待检测。切换后释放主机输入、取消失效反馈、清除旧批次原始帧；必须全部松手，下一次新触摸才能再次产生输入。抖动不反复切换。供电变化不会保存或覆盖配置。

保留生产压力算法的滤波、稳定帧数、释放阈值规则和手势抑制。默认无 VBUS 三档的释放阈值分别为 8 / 23 / 58。休眠、强度为零、初始化未完成及硬件故障时仍使用原有触觉保护。

## 配置协议与迁移

- RSTP 报文版本仍为 1，报文 64 字节（Windows Report ID 槽位另计）；握手配置版本为 **3**，正常能力掩码为 **0x7ff**，其中 **0x400** 表示新增三档阈值。
- 配置负载为 52 字节。偏移 0～31 保持原布局；32～47 为四点记录，每点 4 字节：启用、实际动作、半径、步距；48～50 是无 VBUS 三档阈值；51 必须为零。
- 写入校验数值范围、三档顺序和保留位，使用既有保存、状态 7 重启重新枚举及读回流程。旧 Feature 接口和 2.4G Windows 强度／档位同步保留。
- NVS `rstp_config` 使用版本 3 的 60 字节记录。有效 v1／v2 记录自动迁移，保留已有设置，新增值设为 20 / 35 / 70。v2 四点旧反转字段转换为实际动作。迁移保存失败时记录错误，保留原存储记录，当前运行仍可使用迁移后的值。
- 运行时 USB 写入只解释握手声明的 v3 布局，不根据同为 52 字节猜测 v2。需要支持 v3 的配置器。更早固件不能读取 v3 NVS 记录；回退源码不等于回退已保存的配置。

参考配置器文档 `R-SODIUM-Precision-TouchPad-Configurator/docs/hid-protocol.md` 的 v3 字节布局。
**本次按用户要求覆盖其中两条语义：按 VBUS 选择；新增默认值为 20 / 35 / 70。**
配置器仓库未修改，因此其“有线／无线”标签、演示默认值或“恢复默认”操作可能仍使用文档值。以实际设备握手和读回值为准；固件会接受合法的显式配置，不强制把用户保存的值改回默认。
